# Goal of the app

The program should send commands to a REST API to test whether it is responding properly or not.

# Requirements

- Run in a docker container using docker-compose.yaml
- Use: python 3.12 and PySide6
- Create GUI in a ui file to be edited in QtDesigner

# GUI

- Server IP adress and port configurable
- Method GET/POST configurable
- Payload configurable
- See the response of the server
- GUI simple and modern looking

# Aditional requirements

- The user should be able to save several configurations to be used later. Multiple configurations can be saved in one file and a name can be set for each of these configurations. The format to save the data will be JSON.
